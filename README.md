## 📌 프로젝트 소개

본 프로젝트는 **온누리마취통증의학과와 연계한 IC-PBL 산학협력 프로젝트**의 일환으로 진행되었습니다.

환자의 증상 데이터를 분석하여 유사한 증상 패턴을 가진 질병을 예측할 수 있는 머신러닝 모델을 개발하였습니다.

텍스트 형태의 증상 데이터를 **TF-IDF(Term Frequency–Inverse Document Frequency)** 방식으로 벡터화하여 특징을 추출하고, **K-Means 클러스터링**을 통해 유사한 질병을 군집화하였습니다.

또한 **Elbow Method**와 **Silhouette Score**를 비교하여 최적의 군집 개수를 선정하고, **NDCG(Normalized Discounted Cumulative Gain)** 지표를 활용하여 모델의 추천 성능을 평가하였습니다.

## ⚙ 프로젝트 진행 과정

### 1. 데이터 전처리

* 결측 데이터 처리
* 불필요한 문자 제거
* 증상 데이터 정제
* 학습 데이터 구성

</br>

### 2. TF-IDF 특징 추출

증상 텍스트를 TF-IDF 방식으로 벡터화하여 질병을 구분하는 핵심 증상에 높은 가중치를 부여하였습니다.

이를 통해 텍스트 데이터를 머신러닝 모델이 학습 가능한 특징 벡터로 변환하였습니다.

</br>

### 3. K-Means 클러스터링

TF-IDF 벡터를 기반으로 K-Means 클러스터링을 수행하여 유사한 증상을 가진 질병을 동일한 군집으로 분류하였습니다.

이를 통해 새로운 환자의 증상이 입력되었을 때 가장 유사한 질병 군집을 탐색할 수 있도록 구현하였습니다.

</br>

### 4. 최적 군집 개수 선정

클러스터링 성능을 향상시키기 위해 **Elbow Method**와 **Silhouette Score**를 함께 활용하여 최적의 군집 개수를 분석하였습니다.

### 엘보우 기법 (Elbow Method)

* 군집 내 오차 제곱합(SSE)의 감소율을 분석
* Elbow Point가 **6개**에서 나타나 최적 군집 개수 후보로 선정

### 실루엣 계수 (Silhouette Score)

* 군집 간 분리도와 응집도를 평가
* 가장 높은 실루엣 계수는 **88개의 군집**에서 나타남

그러나 88개의 군집은 데이터가 지나치게 세분화되어 새로운 데이터에 대한 일반화 성능과 실제 활용성이 낮다고 판단하였습니다.

따라서 **모델의 활용성과 해석 가능성을 고려하여 Elbow Method에서 도출된 6개의 군집을 최종 모델에 적용**하였습니다.

## 📊 모델 평가

본 모델의 예측 성능은 추천 순위의 품질을 종합적으로 평가하는 **NDCG (Normalized Discounted Cumulative Gain)** 지표를 활용하여 검증하였습니다. NDCG를 통해 예측된 질병의 순위가 실제 질병과 얼마나 일치하는지를 측정하여, 단순 정확도뿐만 아니라 **추천 순위의 품질**까지 함께 평가하였습니다.

### 평가 결과

- **NDCG@5 = 0.97**
  - 환자의 증상 정보를 바탕으로 실제 질병이 **상위 5개의 추천 결과에서 매우 높은 순위로 제시**되어, 핵심 후보군을 효과적으로 선별함을 확인하였습니다.

- **NDCG@10 = 0.51**
  - 추천 범위를 상위 10개까지 확장했을 때 추천 순위의 품질이 상대적으로 낮아지는 경향을 확인하였습니다. 이는 상위권 이후의 후보 질병들이 실제 질병과의 관련성이 낮아지면서 전체 추천 순위의 품질이 감소했음을 의미합니다.

### 결론

본 모델은 **실제 질병을 상위 5개 후보 내에 높은 정확도로 추천하는 데 강점**을 보였습니다. 다만 추천 범위를 더 넓힐 경우에는 후순위 후보의 품질을 개선하기 위해 **추가적인 특징(Feature)이나 임상 정보**를 활용한 모델 개선이 필요함을 확인하였습니다.
